Backups

Each backup is a full snapshot — the database and the on-disk files it only stores paths to (job-capture receipt photos, Winston report images). An automatic snapshot is created on every server start (before migrations) and daily at midnight Arizona time. The last 13 are kept. Download a backup before making risky changes.

Restore from Backup

Upload a .zip full backup (from this page, or another DoorFlex instance) to restore the database and the photo files together — the way to recover everything after a data disaster. A plain .db file is also accepted for older, database-only backups, but won't bring photos back. The current state is backed up first before anything is replaced.
